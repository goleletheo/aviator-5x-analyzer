# AI Aviator 5x Analyzer

Educational tool to analyze the frequency of 5x+ multipliers in Aviator-style crash games.

## Features
- Theoretical probability (19.4% for 5x+)
- Round simulator
- History analyzer
- Live visual demo

**Disclaimer:** Past results do not predict future rounds. This is not a predictor. 18+ only. Play responsibly.

Open `index.html` in a browser or deploy as a static site.
